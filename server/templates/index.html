Connect your own API key

Each person uses their own key from Google AI Studio. The assistant does not keep one key for everyone.

  1. Sign in at Google AI Studio.
  2. Open the API keys page and accept the terms if asked.
  3. Copy the key already there, or choose Create API key and put it in a project you can recognise.
  4. Paste it into AI Support Agent, pick a model, and start talking.

A saved key is encrypted on this server and shown only by its last four characters. You can instead keep it for this visit only, in memory, and leave nothing on disk. Delete the key here, or delete it in AI Studio, whenever you want.
